#---DICTIONARY ATTACK Python Bash Script 
- Challenge from NEIU HACKFEST 2025: https://www.hackerrank.com/contests/neiu-hackfest-2025/challenges/cy-dictionary-attack/problem

#---Features
- Plain password lookup
- Reversed password variant
- Vowel-removed password variant
- Three salt prefix combinations per variant


#---System Reqs
- Python 3
-`passwords.txt`

#---Instructions
1. Add your wordlist as `passwords.txt` in the same directory
2. Run the script:
./dictAttack.py
3. Enter an MD5 hash when prompted
4. Type `quit` to exit
